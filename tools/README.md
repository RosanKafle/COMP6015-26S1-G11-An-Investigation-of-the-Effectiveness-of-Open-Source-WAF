# Reproducibility Tools

This folder contains the scripts used to reproduce the automated and manual validation results.

The tools are included for transparency and reproducibility. The main project evidence is stored under:

- `output/` for automated experiment outputs
- `evidence/manual_validation/` for manual validation evidence
- `analysis/` for processed summary tables

## Folders

- `automated_framework/`: Python framework for ZAP-driven automated WAF experiments.
- `manual_validation/`: scripts used to execute and summarise curated SQLi and CSRF manual validation tests.
