# Environment and Provenance

- Host machine: macOS with VMware Fusion
- Attacker VM: Kali Linux
- Target lab: DVWA with ModSecurity plus OWASP CRS and Coraza plus OWASP CRS
- Repo role: exported evidence archive copied from tests run in the VMware Fusion lab

## Interpretation note

The files in `docs/` reflect what was saved or exported from the testing lab at the time of execution. This repository does not contain the full live server configuration, container definitions, or VM images.

Missing runtime files in this repository should be interpreted as not exported into the evidence set, not as proof that the environment did not exist.
