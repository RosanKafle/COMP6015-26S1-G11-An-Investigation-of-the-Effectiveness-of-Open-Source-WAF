# Final Project Scope

This project evaluates the effectiveness of open-source Web Application Firewalls using DVWA only as the vulnerable web application.

The application was tested under three conditions:

1. No WAF
2. ModSecurity with OWASP Core Rule Set
3. Coraza with OWASP Core Rule Set

The final evidence chain focuses only on DVWA-based web application firewall testing. Any unrelated network-security files, such as Suricata, SYN, or SSH testing outputs, are excluded from the final analysis.
