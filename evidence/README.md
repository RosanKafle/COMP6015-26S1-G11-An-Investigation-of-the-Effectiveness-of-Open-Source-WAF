# Evidence Folder

This folder contains evidence collected outside the structured automated experiment output.

## Primary Contents

- `manual_validation/` contains curated manual SQL injection and CSRF validation evidence.
- `manual_validation/payloads/` contains the manual test definitions.
- `manual_validation/results/` contains raw result CSVs and derived summary tables.

## Optional Supporting Material

- `screenshots/` is reserved for screenshots.
- `logs/` is reserved for exported logs.
- `notes/` is reserved for extra observation notes.

The main raw automated experiment evidence is in `output/`, and historical weekly evidence is in `docs/`.
