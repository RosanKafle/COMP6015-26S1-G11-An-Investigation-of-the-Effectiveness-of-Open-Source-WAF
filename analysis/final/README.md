# Final Analysis Outputs

This folder contains report-ready analysis files generated from `output/`.

## Main Files

- `report_summary.md` - report-ready summary tables.
- `key_findings.txt` - concise generated findings.
- `final_summary.csv` - per-run headline metrics.
- `final_attack_type_summary.csv` - attack outcomes by attack type.
- `final_benign_summary.csv` - benign traffic outcomes.
- `final_waf_comparison.csv` - WAF comparison table.
- `final_repetition_summary.csv` - repeated-run summary.
- `final_classification_matrix.csv` - true attack type versus detected type.
- `final_classification_summary.csv` - alert classification summary.

Additional CSV files support deeper breakdowns and missed-attack analysis.
