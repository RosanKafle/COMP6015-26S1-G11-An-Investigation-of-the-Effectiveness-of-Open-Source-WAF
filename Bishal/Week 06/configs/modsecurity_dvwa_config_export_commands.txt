ModSecurity and DVWA configuration command reference

Useful setup/version commands:

apache2 -v
apache2ctl -M
dpkg -l | grep -Ei "apache2|modsecurity|coreruleset|crs"
grep -R "SecRuleEngine" /etc/modsecurity /etc/apache2 -n
grep -R "Include.*crs\|Include.*coreruleset" /etc/apache2 /etc/modsecurity -n

Configuration files used for setup records:

- /etc/modsecurity/modsecurity.conf
- /etc/modsecurity/crs/crs-setup.conf
- /etc/apache2/sites-enabled/*.conf
- DVWA config file, with passwords redacted if needed

These commands are kept as a reproducibility reference for the lab environment.
