# Week 01 Project Scope and Roles

## Focus

Background reading, tool installation, and initial project planning.

## Project Direction

The project investigates the effectiveness of open-source web application firewalls by placing a WAF in front of a vulnerable web application and comparing behaviour before and after protection is enabled.

The planned evaluation measures:

- Attacks blocked by the WAF.
- Attacks detected but allowed.
- Attacks that bypass protection.
- False positives against normal requests.
- Performance and usability impact.

## Team Role Structure

- Project Manager and Client Liaison: schedule, progress tracking, communication, weekly summaries.
- WAF and Infrastructure Engineer: vulnerable application, web server, WAF, CRS configuration.
- Tools and Attack Lead: ZAP, Burp Suite, SQLMap, Nikto, Wapiti, and attack campaigns.
- Measurement, Analysis and Documentation: data templates, result tables, analysis, report writing.

## Week 01 Outputs

- Initial concept note on WAFs and open-source WAFs.
- Shared repository and weekly evidence structure.
- Tool installation plan for ZAP, Burp Suite, SQLMap, Nikto, and Wapiti.
- Initial OWASP Top 10 reading focus.
