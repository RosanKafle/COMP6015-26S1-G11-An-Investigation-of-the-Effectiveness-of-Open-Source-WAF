Paired performance baseline command reference

The weekly report claims comparison with and without WAF.

Imported group evidence:
- Baseline/no-WAF, ModSecurity, and Coraza ApacheBench outputs were imported into github_tools_attack_lead_week8_performance.
- The folder now has enough shared-team evidence for a basic paired performance comparison.

Repeatable WAF states:

1. WAF disabled or SecRuleEngine Off.
2. SecRuleEngine DetectionOnly.
3. SecRuleEngine On with default CRS.
4. SecRuleEngine On with CRS paranoia level 2.

Commands:

ab -n 100 -c 10 http://192.168.56.20/ > ab_<state>_run1.txt
hey -n 100 -c 10 http://192.168.56.20/ > hey_<state>_run1.txt

Repeat each state three times if possible.

Record:
- Requests per second.
- Mean response time.
- 95th percentile latency.
- Failed requests.
- HTTP status distribution.
