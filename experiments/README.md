# Experiments

This directory separates later controlled evaluations from the repository's
primary automated evaluation at the root.

- `modsecurity-naxsi/implementation/` contains the maintained Semester 2 test
  implementation and its reviewed final results.
- `modsecurity-naxsi/reviewed-data/` contains the retained reviewed inputs and
  provenance records that were previously identified only as Week 6.
- `r11-r12/` contains the R11 and R12 controlled WAF evaluation.

Results from these experiments use different corpora and validation methods and
must not be pooled into a single effectiveness percentage.
