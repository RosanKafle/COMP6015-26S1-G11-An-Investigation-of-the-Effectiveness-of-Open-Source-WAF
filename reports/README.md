# Reports

This folder contains report documents separated from raw analysis data.

- `final/` contains final or near-final Word report versions.
- `drafts/` contains earlier report drafts.
- `tables/` contains table-only report exports and technical-note variants.

Use `final/COMP6015_Group11_WAF_Final_Report_SubmissionReady.docx` as the submission-ready report version.

The CSV and Markdown sources for these reports remain in `analysis/final/`.
