# Individual Contributions

This directory groups contributor-specific analysis and preserved evidence.

- `bishal/` contains the reviewed ModSecurity/NAXSI evidence package and its
  preserved source archive.
- `pabin/` contains the independent evidence analysis and validation work.
- `roshan/` contains cross-branch inventories, validation outputs and analysis.
- `sadaiba/` points to the controlled R11/R12 WAF evaluation and its preserved
  evidence under `experiments/r11-r12/`.

These names identify authorship, not separate experiments. Follow the links in
each contribution to the corresponding data under `experiments/` or the primary
root-level evaluation.
